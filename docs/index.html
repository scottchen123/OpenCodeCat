OpenCodeCat

桌面上的一只小猫，顺手看一眼用量。不绑定任何中转，任意渠道都能接。

下载最新版 dmg GitHub 仓库

macOS 13 及以上 · Apple Silicon · 菜单栏和 Dock 都不占图标

特性

常驻桌面

一只像素小猫加一个月度百分比，不占地方，位置随便拖，记住后下次还在原地。

三档用量

悬停展开 5 小时 / 周 / 月三条进度，单击看完整额度与重置时间。

颜色预警

绿、黄、橙、红四段变色，月额度到 90% 出一条提醒。

Key 只存本机

渠道 Key 只保存在你的电脑上，不上传到任何地方。

快速开始

  1. 下载安装

    从 Releases latest 下载 OpenCodeCat-macOS-arm64.dmg，双击打开后把 OpenCodeCat 拖进 Applications，再双击运行。

  2. 填 Key

    第一次打开如果提示找不到 Key，用下面任意一种方式配置，保存后自动刷新：

    界面配置
    点详情面板右上角齿轮，填名称和 Key，用量接口填你的中转地址。
    文件 / 环境变量
    写 ~/.opencode-usage-key 或设 OPENCODE_GO_API_KEY。

  3. 开始用

    桌面上多出一只猫：悬停看三档用量，单击开关详情，右键刷新或退出。每 60 秒自动刷一次。

echo -n "你的key" > ~/.opencode-usage-key
chmod 600 ~/.opencode-usage-key
# 或 export OPENCODE_GO_API_KEY=你的key

日常用法

拖动
按住小猫拖，位置自动记住
悬停
展开 5 小时 / 周 / 月三条进度
单击
打开、关闭详情：完整额度与重置时间
右键
刷新、放回右上角、隐藏、退出
低于 40% 低于 70% 低于 90% 90% 起

其他

  • 每 60 秒自动刷一次，详情里也能点立即刷新
  • 不绑定渠道：只要回包里有 rolling、weekly、monthly 各自的 percent 就能直接用，缺字段会自动容错
  • 齿轮里可以恢复默认设置
