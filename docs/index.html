OpenCodeCat

桌面上的一只小猫，顺手看一眼用量。不绑定任何中转，任意渠道都能接。

下载最新版 dmg

macOS 13 及以上 · Apple Silicon · 菜单栏和 Dock 都不占图标

装上就能用

  1. 从 Releases latest 下载 OpenCodeCat-macOS-arm64.dmg
  2. 双击打开，把 OpenCodeCat 拖进 Applications，再双击运行
  3. 桌面上多出一只猫，位置随便拖，关掉重开还在原地

设置 Key

第一次打开如果提示找不到 Key，点详情面板右上角的齿轮：名称随便填自己区分渠道用，Key 粘贴进去（默认脱敏，点眼睛看全文），用量接口填你的中转地址就行。保存后自动刷新，Key 只存本机，不会上传到任何地方。

也可以提前写好文件，或者用环境变量：

echo -n "你的key" > ~/.opencode-usage-key
chmod 600 ~/.opencode-usage-key
# 或 export OPENCODE_GO_API_KEY=你的key

日常用法

拖动
按住小猫拖，位置自动记住
悬停
展开 5 小时 / 周 / 月三条进度
单击
打开、关闭详情：完整额度与重置时间
右键
刷新、放回右上角、隐藏、退出
低于 40% 低于 70% 低于 90% 90% 起

其他

  • 每 60 秒自动刷一次，详情里也能点立即刷新
  • 不绑定渠道：只要回包里有 rolling、weekly、monthly 各自的 percent 就能直接用，缺字段会自动容错
  • 齿轮里可以恢复默认设置
